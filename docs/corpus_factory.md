# コーパス工場 生成規格書（名勝負ライブラリのストック生産）

手動バッチ（content係）と毎日のスケジュールタスクが共通で従う正典。変えたらここを直す。

## 目的
Claude（Opusサブエージェント＝サブスク枠内）で高品質バトルを量産し、`docs/claude_corpus.jsonl` に蓄積する。
用途: ①アプリの既定エンジン「名勝負ミックス」の素材（各バースを2行ずつに切り、同じ相手・同じ韻の2行組を別のバトルから繋いで1バースにする。index.html の parseCorpus 以下）②A案（旧・単語シグネチャ方式）への採掘素材。
**2番目以降のバースの冒頭2行は「相手の締め語を拾う返し」として組み替えから除外される**ので、返しの工夫はそこに集めてよい（他の行は他の文脈に移せる書き方を意識する）。
**各バースの3行目は、なるべく接続語（だが・でも・その・それ・そして・だから・つまり）で始めない**。3〜4行目の2行組はバースの頭にも回せる素材になるが、接続語で始まると頭に置けない。
**人格設定（personas.md）の決め台詞・dis・respect の文言は、そのまま書き写さず毎回言い換える**（2026-09-28）。「一年を読み切る」「心白という上質な土台」「りんごの香り」「糖化の設計」などを丸写しすると、組み替えたバトルで同じキャラが同じ台詞を何度も言う。看板語（signature）は1バトルで各キャラ2回まで。
**コーパスは公開データ（2026-09-24 ユーザー判断）**: `docs/claude_corpus.jsonl` はgit管理・GitHub Pagesで配信され、`docs/corpus_viewer.html`（アプリのフッター「遊び心」の隠しリンク）から閲覧できる。公開版への反映はpush時（毎朝の自動生産分はローカルに溜まり、pushで公開）。`docs/corpus_batches/`（並列バッチの中間ファイル）は引き続きgit管理外。

## スキーマ（1バトル=1行のJSONL・整形JSON不可）
`docs/claude_corpus.jsonl` の既存行を必ず1行読んで踏襲する。要点:
- `{ts, model:"claude-opus-sub", aId, bId, bars:8, mode:"claude-teacher"（がっつり回は "claude-teacher-hard"）, style, theme, data:{verses:[...4個], flavor}}`
- verses は a,b,a,b の順。各バース `{characterId, characterName, displayRhyme, lines:[4行]}`
- ts は生成時刻のISO文字列。aId/bId は koji/yeast/toji/lactic/rice

## 品質基準
- 各バースの行末を**母音末尾3つ一致**でそろえる（拗音は2母音と数える）。displayRhymeに主韻を書く
- **日本語の意味が通ることが韻より優先**。人格は `docs/personas.md` に従う（dis/respect/一人称/口調）
- 実在しない醸造用語を作らない（怪しければ一般語に逃がす）。大言壮語（最強・無敵・伝説等）は歓迎
- 1バース内で同語3回は不可

## 押韻の決まり（2026-10 改定。根拠は `docs/rhyme_research_2026-10.md`、試作と検証係の読み比べで確定）
1. **行末の韻語を先に決め、そこへ着地する文を後から書く**。各バースでまず行末4語（同じ韻）を選び、各行をその語へ自然に着地させる（逆向き生成。詰め込みを防ぐ）
2. **韻は語幹で3母音以上**。「締める／求める」のように活用語尾（〜る）で稼いだ一致は数えない（〜える動詞が並ぶと実質1母音しか踏んでいない）
3. **行末の形を散らす**（各バース）:
   - 動詞の終止形で終わる行は **1〜2行**（0行も避ける）
   - **「〜の【名詞】」で締める行は2行まで**（「菌どもの頭／一本の柱」型が並ぶと単調）
   - **1行は名詞以外で着地**（形容詞・形状詞・言い切れる連用形・命令形・倒置）。連用形は言いさしに読めないように
4. **中韻は句の切れ目（読点・助詞の直前）に1つ・目安**。その行の行末と同じ韻の語を置き <span class="rhyme">…</span> で囲む。不自然になるなら入れない（強制すると意味が崩れることを試作で確認）
5. **深い韻は語をまたいでよい**（「蔵の孤独／もろみの鼓動」のように2語で4母音以上）。1バースに1組あれば上出来、無理はしない
6. **子音が近いと加点**（韻の2音節目以降で m・nどうし、拗音どうし、か行とが行・た行とだ行のような同じ口の位置）。必須ではない
7. **使用済みの韻語の組は使わない**: `docs/rhyme_pairs_ledger.txt`（1行1組「語A|語B」、`tools/factory.py append` のたびに自動で作り直される）にある組は避け、候補の語を Grep で台帳に当てて確かめる。台帳2行目の「多用語」もなるべく韻語にしない。同じバッチ内でも同じ組は1回まで

## がっつり回の決まり（1日1本・2026-10-06 オーナー判断）
`tools/factory.py plan` の割り当て表で「がっつり回」と出た1本は、上の押韻の決まりより韻の量と深さを大きく上げて書く。**mode は "claude-teacher-hard"**（ほかは "claude-teacher"）・お題なし。
1. 行末4語すべてを**語幹で4母音以上**（できれば5母音）。活用語尾で稼がない
2. **毎行2回以上踏む**: 句の切れ目の中韻＋行末。中韻の語も行末と同じ韻にそろえ印を付ける
3. **語をまたぐ多音節韻**を積極的に（「形容詞＋名詞」で母音を伸ばす作り方が効く）。**言葉遊び（掛詞）を乗せる**と深い韻でも窮屈にならない
4. 子音もできるだけ寄せる。使用済みの韻語の組は使わない（台帳）
5. 意味が通ることは最優先のまま。「〜の【名詞】」締めは2行までの決まりは守る。動詞止め0行は許す（4母音を全行でそろえると作りにくいため）
（試作 2026-10-07_HARD: 語幹で数えた韻長 平均4.25母音・4母音以上の組が全バース・中韻が全16行。標準は3.02母音・19%・15%）

## 作風ローテーション（偏り防止。曜日または担当バッチで回す）
1. 王道戦: standard多め・テーマ薄め（基本の名勝負）
2. 毒舌回: savage多め（dis全開・ただし醸造の事実に基づく攻め口）
3. 季節テーマ戦: 花見・梅雨・夏の火入れ・秋あがり・雪の仕込み・正月 など（お題つきは半数まで。残りはお題なしで季節の口調だけ）
4. 変わり種テーマ戦: 停電の夜・品評会落選・後継者問題・海外輸出・百年蔵の記念日・AI導入 など（お題つきは半数まで）
5. リスペクト戦: standard・相手を認めつつ超える構成
- ペアは全10組をまんべんなく。乳酸菌・杜氏・酒米など薄いペアを優先的に厚く
- **どの作風の日も、半数以上はお題なし（theme空）にする**（2026-09-27）。お題なしの2行組はアプリの「名勝負ミックス」でどのバトルにも組み込める共通素材になり、お題つきは同じお題どうしでしか組めない（お題つきが7割だとバトル途中でお題が切り替わる率が58%になった）。季節・変わり種の日も、お題なしの戦で作風の口調だけ保てばよい

## 出力先と検証（追記事故防止のプロトコル）
- **手動バッチ（並列時）**: `docs/corpus_batches/YYYY-MM-DD_<記号>.jsonl` に自分専用ファイルで書く（マスターへ直接追記しない）。マージは本体が検証後に行う
- **スケジュールタスク（単独実行）**: マスター `docs/claude_corpus.jsonl` へ直接追記してよい。ただし追記前に既存行数を数え、追記後に「全行 json.loads 可・verses4×lines4」を必ず検証。検証コマンド:
  `python3 -c "import json;rows=[json.loads(l) for l in open('docs/claude_corpus.jsonl')];assert all(len(r['data']['verses'])==4 and all(len(v['lines'])==4 for v in r['data']['verses']) for r in rows);print(len(rows),'行OK')"`
  検証に失敗したら自分の追記行を取り除いて戻す
- index.html・lint.js・docs/の他ファイルは触らない

## 記録
- スケジュールタスクは実行後、Vault `📤受け渡し/当日.md` の「💡今日やったこと」に1行（例: `- 醸造ラップバトル工場: 6本追加（累計N本・作風=季節テーマ戦）`）
- ストックが+50本たまるごとに、通常セッションで校正（採掘→A案還元 or 名勝負選定）を回すのが目安
