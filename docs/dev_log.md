## 2026-07-15 B案→A案 蒸留フライホイール
別途Antigravityが index.html に Gemini AIモード(B案・オプトイン／デフォルトはA案テンプレート)を追加済み。ユーザー評価「B案の出力はかなり良い」。そのB案出力を"教師"にしてA案の素材(語彙・フレーム)を採掘する仕組みを構築した。
- **考え方**: A案はMLでないので「学習」ではなく蒸留/採掘。LLMが創造性・自然さ・網羅性を供給、A案の検証ハーネス(韻100%/意味lint/反復)が"品質ゲート"。ゲートを通った候補だけ取り込む＝LLMが変な出力をしてもA案は壊れない。
- **オフライン原則の維持**: 採掘は開発時のオフライン処理。A案の実行時にAPIは呼ばない。B案=素材工場、A案=完成品。
- **蓄積UI(index.html)**: B案成功時に構造化出力を localStorage(`brew_corpus`) へ蓄積 → フッター上の「コーパストレイ」から `gemini_corpus.jsonl` を書き出し(docs/へ)。ブラウザは任意ファイルに直接書けないのでlocalStorage→ダウンロード方式。**APIキーはコーパスに含めない**（saveToCorpusのレコードにapiKey無し）。
- **採掘器**: `docs/dump_engine.js`(既存VOCAB/role/formをJSON化) → `docs/mine_corpus.py`(pykakasi読み＋vowels()移植でsig3計算)。①新語彙候補を [ドロップイン(既存sig3+form一致)] / [新バケット(新sig3)] / [要読み校正] に分類 ②行を韻語→スロット化してフレーム候補を抽出。
- **運用ループ**: B案で回す→書き出し→`node docs/dump_engine.js > /tmp/engine_dump.json`→`<venv>/bin/python docs/mine_corpus.py docs/gemini_corpus.jsonl /tmp/engine_dump.json`→人が校正→index.htmlに追加→lint/harness/rep 全緑で確定。回すほどA案が濃くなる。

- 注意: pykakasiは venv 必要（`python3 -m venv venv && venv/bin/pip install pykakasi`）。scratchpad上のvenvはセッション跨ぎで消えることがある。

AI出力のテーマがランダムだった問題への対処。B案/C案で**お題を指定**できるように（A案はテンプレなので対象外＝非表示）。
- UI: 「お題」テキスト入力＋`<datalist>`で候補12種（伝統vs革新／生酛vs速醸／香り重視vs味わい重視／純米vsアル添／手作業vs機械化／夏酒vs燗酒／山田錦vs新品種／コストvs品質／精米歩合／熟成vs搾りたて／海外展開／若手vsベテラン）。自由入力も可。**空欄=おまかせ**（従来通り）。localStorageに保存。
- `themeDirective()` が指示文を生成し、Gemini/Ollama両プロンプトへ注入（styleDirectiveの隣）。「テーマから逸れた一般論に流れない」を明示。
- **コーパスに `theme` と `style` を記録**（保存レコードに追加）。後で「このお題/スタイルの時の言い回し」を採掘できる。
- 検証(C案・乳酸菌×杜氏・お題「生酛 vs 速醸」): 「速醸で蔵が白麹、我が時間無視／生酛の深み、お前より俺の心白」とお題の対立軸に沿った出力。コーパスにtheme記録も確認。A案は全チェック緑。
