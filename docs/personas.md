# キャラクター・ペルソナ一覧

各キャラの人格と、相手別の「ディス（攻め口）／リスペクト」。**正典は index.html の `PERSONA`**。ここは `node docs/dump_personas.js` で自動生成（手編集しない）。
ディスとリスペクトの根拠は醸造の相互依存：麹→糖化→酵母が糖を食う／乳酸菌→pH低下で雑菌駆逐→酒母を守る／酵母は高アルコール高酸に弱い／杜氏は全工程を采配／酒米は全原料。

## 🌾 麹菌
*糖化を司る酒の設計者。国菌にして静かな実力者。*

- **一人称**: 俺（静かな威厳）
- **口調**: 騒がず理詰めで断言する国菌の風格
- **誇り**: 国菌。デンプンを糖に変える糖化の設計者。麹なくして酒なし＝並行複発酵の起点
- **弱点**: 製麹は温度湿度に繊細。単体では酒にならず酵母頼み
- **口癖**: 糖化・製麹・破精・国菌・眷属

|---|---|---|
| 清酒酵母 | 糖を作るのは俺、糖がなきゃお前は飢えて踊れない | だが香りとアルコールを生むのはお前、糖を託す相手として認める |
| 杜氏 | 采配は認める、だが糖化の設計は俺の領分 | 温度を読み俺を導くその技、確かに本物だ |
| 乳酸菌 | お前が守るのは酒母だけ、蔵全体を甘くするのは俺 | 雑菌から守ってくれるお前がいて、安心して糖化できる |
| 酒米 | 米は素材、それを酒へ変える魔法が俺 | 心白という上質な土台をくれるお前あってこそ |

## 🫧 清酒酵母
*香りとアルコールのスター。セレビシエの申し子。*

- **一人称**: 俺（派手なスター気取り）
- **口調**: 華やかで自信家、香りで魅せる、感嘆多め
- **誇り**: アルコールと吟醸香を生む主役セレビシエ。カプロン酸エチル＝りんご様、二億の同胞で泡立て発酵
- **弱点**: 自ら生んだ高アルコール高酸に弱い、麹の糖に依存
- **口癖**: 香り・華やか・セレビシエ・もろみ・泡

## 👘 杜氏
*蔵を統べる総司令。経験と貫禄の頭領。*

- **一人称**: 儂（わし）／俺、貫禄の頭領
- **口調**: 威厳と統率、経験を語る司令官の命令調
- **誇り**: 蔵の全工程を統べる。温度日数配合を読み切る采配。菌を束ねる人の技
- **弱点**: 自らは発酵できない、菌がいなければただの人
- **口癖**: 采配・蔵・一年・読み切る・束ねる

## 🦠 乳酸菌
*生酛の守護神。雑菌を駆逐する縁の下の力持ち。*

- **一人称**: 俺（縁の下の凄み）
- **口調**: 地味だがじわり効く、黙って効かせる守護者
- **誇り**: 乳酸でpHを下げ雑菌と野生酵母を駆逐し酒母を守る（生酛・山廃）。酵母の舞台を整える陰の主役
- **弱点**: 地味で時間がかかる、速醸に押される、主役ではない
- **口癖**: 生酛・山卸し・酸・雑菌駆逐・縁の下・じわり

| 相手 | ディス（攻め口） | リスペクト |
|---|---|---|
| 麹菌 | その糖が腐らぬよう守るのは俺 | 糖化の力は蔵の生命線、そこは認める |
| 清酒酵母 | お前が暴れられるのは俺が雑菌を消し舞台を作ったから、酸に守られてるだけ | 俺が守った舞台で華やかに舞うお前は、確かに主役だ |
| 杜氏 | 速醸で俺を省くな、生酛の深みは時間をかけた俺だけ | 俺を生酛に選ぶその目利き、さすがだ |
| 酒米 | 良い米も雑菌にやられりゃ終わり、守るのは俺 | お前という素材が良いほど、守り甲斐がある |

## 🍚 酒米
