# 固有名詞の語彙候補表（酒米品種・産地名）vocab_proper_nouns

- 方針1: **蔵名（酒蔵・会社名）は絶対に入れない**（オーナー決定・公開物）。蔵名を含む品種名（白鶴錦）も落とした。
- 方針2: 対象は酒造好適米として通る品種名と、産地名（都道府県は「県」なしの短形＋酒どころの地名）のみ。出典表示は不要だがKBに出現する語だけ。
- 方針3: 母音変換はエンジン準拠（ん/っ飛ばし・ー延長・拗音は「i＋母音」の2母音）。区分＝**ドロップイン**（sig3一致かつ米が入る既存物枠 variety/mill/kakemai/hakumai）／**同居**（sig3は既存roleと一致するがformか意味枠が違う→同softバケットに別roleを新設）／**新バケット**（同sig3・同formが4語以上）／**保留**（それ以外・2母音）。formは「米」「地名」の新form（米は既存の酒米が物で登録されているので、lintでは物扱いでも通る）。index.html・rhyme_reference.md は未変更。

既にエンジンにある酒米6語（山田錦・美山錦・八反錦・神力・たかね錦・千本錦）は表から除外。

混成で4語に届くもの（別form 2roleの同居前提・要判断）: oaa＝富山/大阪/吉野川(地名3)＋蔵の華(米1)／iue＝渡船3(米)＋瓶詰め(工程)／iou＝北海道/西条/西郷(地名3)＋改良信交(米1)＋既存gin。

足さない案: 産地は名門ほど2母音（灘・能登・南部・丹波・加賀・土佐）で3母音韻に乗らず、都道府県だけ足すと「地名の羅列」になりやすい。まず酒米キャラに **oai 雄町一族6語** だけ足して反復率を rep.js で見る。産地は足さない選択も残す（地名は「〇〇の」で修飾語にした方が優しく響く可能性）。
